# 神戸みらい法律事務所 デモサイト

添付デザインを参考に、React + Vite + JavaScript + CSS Modulesで構築した1ページサイトです。

## 起動方法

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
```

## 主な機能

- レスポンシブ対応
- スマートフォン用ハンバーガーメニュー
- FAQアコーディオン
- スムーススクロール
- TOPへ戻るボタン
- コンポーネント分割
- CSS Modules

画像はプロジェクト内のダミーSVGを使用しています。
